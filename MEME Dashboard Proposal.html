Overview

Project Summary

Copper State Credit Union currently tracks member experience across nine distinct channels, compiled manually each month into a spreadsheet. This proposal outlines a two-phase engagement to transform that process: first by completing a fully interactive, multi-tab visual dashboard, and second by automating data collection from HubSpot, Talkdesk, and additional sources — eliminating the need for manual reporting entirely.

Phase 1 delivers immediate value with a polished, shareable dashboard. Phase 2 builds the infrastructure to keep it current automatically, month after month.

The Business Case

Cost of the Current Process

The MEME report is currently produced through manual data aggregation across eleven spreadsheet tabs — pulling figures from HubSpot, Talkdesk, and other platforms, calculating scores, formatting outputs, and distributing results each month. When staff time is accounted for at fully-loaded rates, this process is estimated to cost Copper State between $18,000 and $25,000 annually.

This engagement replaces that recurring cost with a one-time investment — after which the dashboard updates itself, every month, automatically.

Scope of Work

Engagement Phases

Phase 1
Dashboard Completion
$4,250
Fixed Fee

The existing dashboard covers two of the eleven spreadsheet tabs. Phase 1 completes the remaining nine, refines visualizations based on feedback, and delivers a fully polished, publicly shareable dashboard hosted on GitHub Pages.

Deliverables
  • 9 additional dashboard tabs built out
  • Consistent design system across all tabs
  • Visualization refinements and feedback iterations
  • Mobile-responsive layout across all tabs
  • Interactive charts with tooltips and filtering
  • Live URL on GitHub Pages, shareable with stakeholders
  • Up to 3 rounds of revision
  • Final file handoff with documentation
Phase 2
Automated Data Pipeline
$7,600
Fixed Fee

Phase 2 eliminates manual data entry by connecting the dashboard directly to HubSpot, Talkdesk, and up to two additional data sources. A scheduled GitHub Actions workflow runs automatically each month, pulls fresh data from each source, and updates the dashboard — no human intervention required.

Deliverables
  • HubSpot API integration (surveys, CSAT, NPS)
  • Talkdesk API integration (chat & phone ratings)
  • Up to 2 additional source integrations
  • Automated monthly GitHub Actions workflow
  • Dynamic data.json layer (dashboard reads live data)
  • MEME score auto-calculation logic
  • Error handling and failure alerts
  • Technical documentation for internal team

Terms & Assumptions

Project Terms

  • Phase 1 requires access to all 11 spreadsheet tabs and timely feedback during revision rounds.
  • Phase 2 requires Copper State to provide HubSpot Private App API credentials and Talkdesk API access prior to development start.
  • Up to 2 additional data sources are included in Phase 2. Each additional source beyond that is scoped and priced separately.
  • Payment terms: 50% deposit to begin each phase, 50% due upon completion.
  • Phases run concurrently to achieve the 4-week delivery target. API credentials and field mapping must be provided no later than end of Week 1 for Phase 2 to remain on schedule.
  • Proposal is valid for 30 days from the date above.
  • Ongoing maintenance and monthly support available following project completion — quoted separately upon request.
